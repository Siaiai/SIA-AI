---
description: 记录 Splan 的 C 变更并更新受影响任务
---
使用 skill 工具加载 `splan`。加载后自报“规划AI”。

参数：`$ARGUMENTS` = `<描述> [--doc <路径>]`。

步骤：

1. 定位文档。
2. 生成下一个 C 号，不复用；定类型：新增 / 修改 / 删除 / 延期 / 否决 / 待定。
3. 变更必须落到某个 R：`新增 R#` / `修改 R#` / `否决 R#`，同步需求登记状态。
4. 影响五个面：任务 / 契约 / 测试 / 文档 / 机制。
5. 更新任务池：
   - 新增 → 加任务，标 `需求：R#`
   - 修改 → 不改旧任务；旧任务进 §6 标取代，新开重做（← C#）
   - 删除 / 否决 / 延期 → 移入 §6，原文保留
6. 更新看板 / 最后更新，跑 lint（-Strict），回复末尾给文档更新回执。
7. 输出新的执行提示词；不 commit / push。
