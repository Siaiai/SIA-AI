---
description: 随时新增需求 / 假设（Splan 唯一需求入口）
---
使用 skill 工具加载 `splan`。加载后自报“规划AI”。

参数：`$ARGUMENTS` = `<需求> [--doc <路径>]`。主对象（需求）在前；`--doc` 可选。

步骤：

1. 定位文档；找不到提示先 `/splan-new`。
2. 新增前先扫：§0 需求登记（R）、§1 任务池（T）、§4 D/C、§3 方案。
3. 查重：按目标 / 验收 / 范围 / 机制比对现有 R/T。重复 → 按 D12 提议合并到最早 R，被并 R 标取消；先列方案等确认，**不静默合并**。
4. 查冲突：与现有 R/T/D/§3 冲突时，列冲突点与取舍；等用户确认后再落文档；未确认不分配 R 号、不建任务。
5. 无重复 / 无冲突后分配下一个 R 号，**永不复用**。
6. 清晰 → `R# 状态=待做`，拆任务（标 `需求：R#`、`机制：复用 X / 新建 D#`）；不清晰 → `R# 状态=待澄清` + 探索任务（时盒 + 产出=结论 + 停止条件）。
7. 关联检查：关联 R#；会引入新机制先立 D。
8. 若文档是交付模式且已有任务，追加 C：`类型=新增`、`需求=R#`。
9. 更新需求登记 / 看板 / 最后更新，跑 lint（-Strict），回复末尾给文档更新回执。
10. 输出下一条任务的执行提示词。
11. 不 commit / push；提交只在 `/splan-done` 按 D15 默认判断。
