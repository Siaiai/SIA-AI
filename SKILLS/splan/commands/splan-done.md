---
description: 完成一条 Splan 任务并更新文档（命令/人工验证；默认判断提交）
---
使用 skill 工具加载 `splan`。加载后自报“规划AI”。

参数：`$ARGUMENTS` = `<任务ID> [--doc <路径>] [--commit / --no-commit]`。

步骤：

1. 开工前运行 `git status`，记录 dirty；只审本任务产出文件，无关改动不提交。
2. 按验证手段处理：
   - **命令**：核对执行AI 回报的命令 + 结果；规划AI 不重跑。
   - **人工**：把步骤发用户确认；未确认只记“待确认”，不勾 `[x]`。
3. 核对不通过：不要勾选。只在 §5 追加 `- [ ] **<ID>** —— 阻塞：…`，回复失败命令与输出摘要。
4. 核对通过：
   - §5 加一行：`- [x] **<ID> 名称** —— 改了什么；验证：<命令或人工> → <结果>；行为：…；结果：通过`
   - 从 §1 移走，加入 §6：结果=完成 / 取消 / 取代 / 延期
   - 更新 §0 看板、下一条、最后更新
   - 关联 C 时更新 §4 处理列
   - 外部笔记回写：R 有 `文档` 时，勾待办项；该 R 全部任务完成才置完成并写 `完成时间`（带秒），未全完成只置进行；笔记缺失 / 找不到待办项记 WARN，不猜
5. 提交：默认判断（本任务文件 + 验证通过 + 文档更新 + lint 0）；`--commit` 强制提交、`--no-commit` 跳过；人工未确认不提交；push 永不自动。
6. 跑 lint（-Strict），ERROR 清零；回复回执（§5 / §6 / §0 / 最后更新 / lint）。
